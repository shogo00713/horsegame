# 🐎 Horse Game (競馬ゲーム)

![CI](https://github.com/shogo00713/horsegame/actions/workflows/ci.yml/badge.svg)

React + TypeScript で実装した、競馬シミュレーションゲームです。  
プレイヤーは所持金を元に馬と賭け方を選び、レース結果に応じた配当を獲得します。

---

## 🚀 デモ

https://horsegame-xi.vercel.app/

---

## 🧠 概要

本ゲームでは以下の流れでレースを実行します。

1. 賭け方（単勝・複勝・馬連・馬単・3連複・3連単）・馬・賭け金を選び、最大 5 口まで同時に BET
2. 馬の強さと、画面に見えない「調子」をもとにした確率抽選で着順を決定し、順位が入れ替わる演出で発表
3. 的中した分を払い戻して所持金へ反映。履歴から馬の調子を推理して、次のレースへ

ログイン不要で、誰でも簡単に遊べます！

## ロジック

#### 馬のレートと調子

- 各馬には、レート(静的)と調子(動的)の2つのパラメータを持たせています
- 調子は、良い方から「絶好調」「好調」「普通」「不調」「絶不調」の5段階あり、各レース後に、確率的に2頭がそれらの調子を入れ替えるという遷移を行なっていきます
  -実際に、馬が持つレースでの基本の強さは、単純にレートの比ではなく、 `(1 / rating) ^ 0.7` によって計算されます （0.7 乗で差を縮めて、大穴が来やすい設定となっています）

#### 馬のオッズ

- 単勝のオッズは、調子の影響を平均化して計算しています。その計算方法は次です。
  1. 調子の配り方を 20,000 通りランダムに作る
  2. それぞれの配り方で各馬の 1 着確率を求め、平均を取る
  3. `オッズ = 払い戻し率（0.9）÷ 1 着確率`（0.1 刻み、最低 1.1 倍）として算出する
- 調子を知らない人は平均して賭け金の約 90% が戻り、調子を読めた人だけがそれを上回れる設計
- これを元に計算されたオッズは、最も強いフェニックスが 3.4 倍、最も弱い漆黒が 20.5 倍となっています

#### 馬の調子の影響

- 実際の各レースでの馬の強さは、基本の強さに、次の調子の換算を与えることで計算されることとなっています（オッズと実際の強さの乖離がおもしろポイント）

| 調子   | 頭数（8 頭中） | 強さへの倍率 |
| ------ | -------------- | ------------ |
| 絶好調 | 1              | ×8           |
| 好調   | 2              | ×5           |
| 普通   | 3              | ×1           |
| 不調   | 1              | ×0.2         |
| 絶不調 | 1              | ×0.05        |

- 各馬に上表の頭数分の調子が割り当てられ、基本の強さにその倍率を掛けたものが、そのレースでの「重み」になる（絶好調の馬は普通の馬の 8 倍、絶不調の馬は 1/20）

#### 順位決定（`logic/race.ts`）

- 各馬の重み = 強さ × 調子の倍率
- 重みに比例した確率で 1 頭を選んで 1 着とし、残りの馬から同様に 2 着、3 着…と最後の 1 頭まで繰り返して着順を決めます
- 結果自体は「BET する」を押した時点で確定しており、7 秒の抽選演出（`logic/drawAnimation.ts`）は、確定済みの着順に向かって順位が入れ替わっていく「見せ方」だけを担当しています

#### 配当計算（`logic/payout.ts` / `logic/odds.ts`）

的中したときだけ `賭け金 × 配当倍率` を払い戻します。

- 単勝: 選んだ馬が 1 着。倍率は馬のオッズ
- 複勝: 選んだ馬が 3 着以内
- 馬連 / 馬単: 1・2 着の 2 頭を当てる（馬連は順不同、馬単は順番どおり）
- 3連複 / 3連単: 1〜3 着の 3 頭を当てる（3連複は順不同、3連単は順番どおり）
- 単勝以外のオッズは、選んだ組み合わせの「的中確率」を単勝と同じ方法（調子の配り方のサンプリング）で求め、`配当倍率 = 払い戻し率 ÷ 的中確率` とする（0.1 刻み、最低 1.1 倍、上限なし）
- 払い戻し率は券種ごとに設定し、手堅い券種は低く、当たりにくい券種は高くしています（現実ならせいぜい70~80%程度のようです）
  - 複勝 85% / 単勝 90% / 馬連 120% / 馬単・3連複 180% / 3連単 450%

#### 賭け方のルール（`logic/betRules.ts`）

- 1 つのレースに、最大 5 口まで同時にベットできます（券種も馬の組み合わせも口ごとに自由。同じ組み合わせの重複も可）
- 賭け方ごとに選ぶ頭数が決まっています（単勝・複勝は 1 頭、馬連・馬単は 2 頭、3連複・3連単は 3 頭）。馬単・3連単は着順まで指定する

## 工夫した点

#### ゲームとしての面白いバランスを目指した、オッズの改善と「調子機能」

一番こだわった点です。「どうすればゲームとして面白くなるか」を考えて、オッズの決め方を見直し、馬の「調子」を取り入れました。

- **きっかけ**: 最初は、各馬のオッズだけで着順を決めるシンプルな作りでした。ただ、遊んでみると、オッズの低い本命馬がほぼ確実に来てしまいます。期待値としては正しくても、当たったときに返ってくるのはオッズ分の少しのお金だけで、ゲームとしてあまり面白みがありませんでした。
- **大穴が来やすくした**: 馬の強さの差を縮める（0.7 乗する）ことで、オッズから見える以上に大穴が来やすくしました。本命ばかりが来る状況を減らすためです。
- **「調子」という見えないパラメータを追加**: 実際の競馬では、レース前に馬の様子を見て、調子を確かめる見方があります。そこからヒントを得ました。ゲームでは、「履歴」でこれまでの着順を見て、馬の調子を確認する形で実装しました。調子を見抜ければ、オッズ以上の見返りを狙えます。
- **オッズの決め方**: こうした要素（強さの差の縮め方と調子）を織り込んだうえでオッズを決めることで、ゲーム全体として面白くなるバランスを目指しました。
- **払い戻し率の調整**: 券種ごとに払い戻し率を変えて、手堅い券種と一発狙いの券種で遊び心地に個性を出し、当たったときにしっかりお金が増える実感が持てるようにしました。
- 数値は、実際に遊びながら試行錯誤して調整しました。

#### 順位が決まるまでも楽しめる抽選演出（`logic/drawAnimation.ts`）

- 着順と払い戻しは「BET する」を押した時点で確定済みなので、すぐに結果を表示することもできます。ただ、ゲームとしての面白さは、結果が出るまでを見守る時間にもあると思いました。
- 当初は、1 秒だけ待って結果をそのまま表示していました。それでも十分に面白かったのですが、結果が決まっているものを、ランダムな動きで順位が入れ替わりながら最終順位に収束していく演出に変えました。
- 最後まで結果が分からず目が離せなくなり、レースを見る楽しさが格段に増したと感じています。
- 演出は見せ方だけを担当していて、着順や配当には影響しません。待てないときはスキップもできます。

#### 設計・開発面

- ロジック（`logic/`）と UI（`components/`）、状態管理（`hooks/`）、データ（`data/`）を分離して、役割ごとにファイルを整理しています
- ロジック層・コンポーネント層・フックにテストを整備し、GitHub Actions で push のたびに自動検証しています
